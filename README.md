# Canoa offline build dependencies

This branch mirrors AI6's `deps` layout. It is **not** the application source branch.

- `pub/`: Flutter/Dart `PUB_CACHE` contents resolved from Canoa's root `app/pubspec.lock` (hosted packages, hashes and version metadata).
- `cdn/`: third-party runtime files needed for offline web builds, keyed by original host and path.
- `manifest.json`: generated hashes, resolved dependency versions and main commit.

Content is generated by the `Refresh deps` GitHub Actions workflow on `main`. The branch is a cache, not a source of executable code from arbitrary sites. Package credentials and caches containing repository-local secrets must never be committed. Do not confuse an empty initial branch with a complete offline build cache.

Usage: `git worktree add ../canoa-deps deps`, then `export PUB_CACHE="$(pwd)/../canoa-deps/pub"`; run `flutter pub get --offline` after the cache refresh succeeds. Building Flutter offline also requires a preinstalled Flutter SDK and its engine artifacts.
