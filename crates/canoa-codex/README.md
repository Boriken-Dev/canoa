# canoa-codex

Canoa's package for Codex: the Store recipe that finds, checks for updates and installs it, and the source preset the host
starts it from when `canoa.cfg` does not name it, beside the re-exported coqui-acp provider that drives it in process. Not published; `canoa-host` depends on it.

Every export is listed in [`AGENTS.md`](AGENTS.md).
